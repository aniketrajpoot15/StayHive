PROBLEM & SOLUTION

Executive Overview & Problem Statement

The Problem
  • High barrier for property hosts to showcase stays.
  • Missing visual location context & map coordinates.
  • Slow page loads due to unoptimized local storage.
  • Lack of verified, authenticated guest reviews.
The Solution
  • Intuitive listing creation with instant geocoding.
  • Interactive Mapbox GL JS map pins & popups.
  • Cloudinary media streaming on a global CDN.
  • Starability animated review rating verification.
Target Audience
  • Guests: Browse, filter by category, explore map coordinates, view reviews.
  • Hosts: Publish properties, edit rates, upload gallery photos.
  • Admins: Oversee content integrity and schema validations.

SECURITY & AUTH

Multi-Layered Security & Authorization

Password Hashing
  • PBKDF2 cryptographic hashing algorithm.
  • Unique randomized 32-byte salt per user.
  • Passwords never stored in readable plaintext.
Role-Based Permissions
  • isLoggedIn: Guards creation & review routes.
  • isOwner: Blocks unauthorized property updates.
  • isReviewAuthor: Only review creator can delete.
Schema Validation (Joi)
  • Strict server-side schema verification.
  • Protects against payload tampering & injection.
  • Client-side Bootstrap feedback validation.
Session Protection
  • HTTP-Only cookies prevent XSS theft.
  • Sessions persisted safely in MongoDB Atlas.
  • Cascade deletion cleans orphaned review data.
DATA MODELING

MongoDB Schema & Relational Modeling

Listing Schema
  • title, description: String
  • image: { url: String, filename: String }
  • price, location, country: String/Number
  • geometry: GeoJSON Point [Lng, Lat]
  • owner: Ref -> User
  • reviews: [ Ref -> Review ]
User Schema
  • email: String (Unique, Required)
  • username: Managed by Passport
  • hash: Binary PBKDF2 hash
  • salt: Unique cryptographic salt
  • createdAt: Timestamp
Review Schema
  • comment: String (Required)
  • rating: Number (1 to 5 Stars)
  • author: Ref -> User
  • createdAt: Date (Default now)
  • Cascade Hook: Auto-deletes on listing remove

ENGINEERING HIGHLIGHTS

Technical Challenges & Implemented Solutions

1. Serverless Asset Bundling & Routing
  • Challenge: Serverless functions lacked local path visibility, causing 404s on stylesheets.
  • Solution: Routed all asset traffic into Express `__dirname` and bundled EJS views via `includeFiles`.
2. Serverless Database Pooling
  • Challenge: Independent Lambda instances risked exhausting MongoDB Atlas connections.
  • Solution: Cached `readyState` check prevents duplicate calls to `mongoose.connect()`.
3. Geocoding Fallbacks & Coordinate Sync
  • Challenge: Vague addresses caused missing coordinates, leading to map rendering crashes.
  • Solution: Added defensive checks on Mapbox feature arrays and fallback coordinates.
4. Document Cascade Deletion
  • Challenge: Deleting a listing left orphaned reviews occupying database storage.
  • Solution: Implemented Mongoose `post('findOneAndDelete')` hook to automatically remove linked reviews.
